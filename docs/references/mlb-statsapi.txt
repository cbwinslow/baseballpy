### Print Phillies 40-man roster on opening day of 2018 season using statsapi.get() and statsapi.roster()

Source: https://github.com/toddrob99/mlb-statsapi/wiki/Examples

```python

### statsapi.lookup_player(lookup_value, gameType='R', season=None, sportId=1)

Source: https://github.com/toddrob99/mlb-statsapi/wiki/Function:-lookup_player

Get data about players based on first, last, or full name. This function returns a list of player dictionaries containing player information such as id, fullName, and primaryPosition.

```APIDOC
## statsapi.lookup_player(lookup_value, gameType='R', season=None, sportId=1)

### Description
Get data about players based on first, last, or full name.

### Method
Function call

### Endpoint
statsapi.lookup_player

### Parameters
- **lookup_value** (string) - Required - The player name to search for (first, last, or full name). For last names that could be part of another last name (e.g., 'Nola' is part of 'Nolan'), append a comma to match on the `initLastName` field (e.g., 'Nola,').
- **gameType** (string) - Optional - Game type to filter by (default 'R').
- **season** (int) - Optional - Season to filter by (default None).
- **sportId** (int) - Optional - Sport ID to filter by (default 1).

### Request Example
```python
player = statsapi.lookup_player('nola,')
print(player[0]['id']) #assume only 1 record returned for demo purposes
```

### Response
#### Success Response
Returns a list of player dictionaries. Each dictionary contains fields such as `id`, `fullName`, and `primaryPosition` (with `abbreviation`).

#### Response Example
```
605400
```

For multiple players:
```python
for player in statsapi.lookup_player('Harper'):
    print('Full name: {}, Position: {}'.format(player['fullName'], player['primaryPosition']['abbreviation']))
```

Output:
```
Full name: Bryce Harper, Position: RF
Full name: Ryne Harper, Position: P
```
```

### Configure logging for MLB-StatsAPI

Source: https://github.com/toddrob99/mlb-statsapi/wiki/Home

Set up Python logging to see MLB-StatsAPI logs. Attach a handler to the 'statsapi' logger and set the appropriate log levels.

```python
import logging
logger = logging.getLogger('statsapi')
logger.setLevel(logging.DEBUG)
rootLogger = logging.getLogger()
rootLogger.setLevel(logging.DEBUG)
ch = logging.StreamHandler()
formatter = logging.Formatter("%(asctime)s - %(levelname)8s - %(name)s(%(thread)s) - %(message)s")
ch.setFormatter(formatter)
rootLogger.addHandler(ch)
```

Calls the MLB StatsAPI and returns JSON data. This function is for advanced querying of the MLB StatsAPI, and is used by the functions in this library.

### Method
GET

### Endpoint
`statsapi.get(endpoint, params, force=False, request_kwargs={})`

### Parameters
- **endpoint** (string) - Required - One of the keys in the ENDPOINT dict.
- **params** (dict) - Optional - A dict of parameters, as defined in the ENDPOINT dict for each endpoint. Defaults to empty dict (`{}`) as of v1.8.
- **force** (boolean) - Optional - If `True`, will force unrecognized parameters into the query string and ignore parameter requirements. Note: results from Stats API may not be as expected when forcing.
- **request_kwargs** (dict) - Optional - A dict of additional parameters to pass to the underlying `requests.get` call. Defaults to `{}`. Of particular interest is `request_kwargs={"headers":{"Accept-Encoding": "gzip"}}`, which is recommended by MLB for some larger endpoints like `game`.

### Request Example
```python
statsapi.get('team', {'teamId':143})
```

### Response
Returns the raw response from MLB Stats API in JSON format.
```

### Python 2 compatibility lines to be removed

Source: https://github.com/toddrob99/mlb-statsapi/wiki/Python-2-Support

These lines apply only to Python 2 and will be removed from the MLB-StatsAPI on or after January 1, 2021. They reload the sys module and set the default encoding to UTF-8, which may affect string encoding for non-ASCII player names.

```python
# Trying to support Python 2.7:
if sys.version_info.major < 3:
    reload(sys)
    sys.setdefaultencoding("utf8")
```

### statsapi.league_leaders(leaderCategories, season=None, limit=10, statGroup=None, leagueId=None, gameTypes=None, playerPool=None, sportId=1, statType=None)

Source: https://github.com/toddrob99/mlb-statsapi/wiki/Function:-league_leaders

Retrieves stat leaders overall or for a given league (103=AL, 104=NL). This function returns formatted text listing the top players in a specified statistical category, with options to filter by season, league, stat group, game types, player pool, sport, and stat type.

```APIDOC
## Function: statsapi.league_leaders

### Description
Retrieves stat leaders overall or for a given league (103=AL, 104=NL). Returns formatted text listing the top players in a specified statistical category.

### Method
Function call

### Endpoint
`statsapi.league_leaders(leaderCategories, season=None, limit=10, statGroup=None, leagueId=None, gameTypes=None, playerPool=None, sportId=1, statType=None)`

### Parameters
- **leaderCategories** (string) - Required - The statistical category to rank leaders by. Available categories can be obtained from the meta endpoint with type=leagueLeaderTypes.
- **season** (int) - Optional - The season to retrieve leaders for. Defaults to current season if not specified.
- **limit** (int) - Optional - The number of leaders to return. Default is 10.
- **statGroup** (string) - Optional - The statistical group (e.g., 'pitching', 'hitting', 'fielding', 'catching'). Available groups can be obtained from the meta endpoint with type=statGroups. Excluding this may return unexpected results.
- **leagueId** (int) - Optional - The league ID (103=AL, 104=NL). If not specified, leaders from all leagues are returned.
- **gameTypes** (string) - Optional - The game types to include. Available game types can be obtained from the meta endpoint with type=gameTypes.
- **playerPool** (string) - Optional - The player pool to filter by. Available values: ['all','qualified','rookies'] (default is 'qualified').
- **sportId** (int) - Optional - The sport ID. Default is 1.
- **statType** (string) - Optional - The type of statistics to use (e.g., 'career', 'statsSingleSeason'). Note: StatsAPI does not appear to support statType='statsSingleSeason' at this time; specify a season or use 'career' to avoid issues.

print( statsapi.league_leaders('earnedRunAverage',statGroup='pitching',limit=10,statType='career') )

Source: https://github.com/toddrob99/mlb-statsapi/wiki/Function:-player_stats

```APIDOC
