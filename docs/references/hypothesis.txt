### Use context manager for per-input setup/teardown

Source: https://github.com/hypothesisworks/hypothesis/blob/master/website/content/2016-08-09-hypothesis-pytest-fixtures.md

Shows how to do setup and teardown for each generated input inside the test function using a context manager.

```python
from contextlib import contextmanager

from hypothesis import given, strategies as st


@contextmanager
def fresh_stuff():
    yield "kittens"  # set up before this line, and tear down after


@given(a=st.none())
def test_stuff(a):
    with fresh_stuff() as stuff:
        assert a is None
        assert stuff == "kittens"
```

### Targeted property-based testing with hypothesis.target

Source: https://github.com/hypothesisworks/hypothesis/blob/master/hypothesis/docs/reference/api.rst

Example of using the target() function to guide input generation towards values that are more likely to falsify a property. The example tests associativity of floating-point addition and uses target(difference) to focus on larger differences. Without this, the test almost always passes.

```python
from hypothesis import given, strategies as st, target

@given(st.floats(0, 1e100), st.floats(0, 1e100), st.floats(0, 1e100))
def test_associativity_with_target(a, b, c):
    ab_c = (a + b) + c
    a_bc = a + (b + c)
    difference = abs(ab_c - a_bc)
    target(difference)  # Without this, the test almost always passes
    assert difference < 2.0
```

### SQLiteExampleDatabase class implementing ExampleDatabase

Source: https://github.com/hypothesisworks/hypothesis/blob/master/hypothesis/docs/how-to/custom-database.rst

A complete example of a custom ExampleDatabase subclass that uses SQLite as the backing store. It implements save, fetch, and delete methods. The move method is not implemented, so the default behavior (delete then save) is used.

```python
import sqlite3
from collections.abc import Iterable

from hypothesis.database import ExampleDatabase

class SQLiteExampleDatabase(ExampleDatabase):
    def __init__(self, db_path: str):
        self.conn = sqlite3.connect(db_path)

        self.conn.execute("""
            CREATE TABLE examples (
                key BLOB,
                value BLOB,
                UNIQUE (key, value)
            )
        """)

    def save(self, key: bytes, value: bytes) -> None:
        self.conn.execute(
            "INSERT OR IGNORE INTO examples VALUES (?, ?)",
            (key, value),
        )

    def fetch(self, key: bytes) -> Iterable[bytes]:
        cursor = self.conn.execute("SELECT value FROM examples WHERE key = ?", (key,))
        yield from [value[0] for value in cursor.fetchall()]

    def delete(self, key: bytes, value: bytes) -> None:
        self.conn.execute(
            "DELETE FROM examples WHERE key = ? AND value = ?",
            (key, value),
        )
```

### Define a composite strategy for ExamInstance with matching answer lengths

Source: https://github.com/hypothesisworks/hypothesis/blob/master/website/content/2020-06-08-complex-data-strategies.md

This example shows a helper function that returns a strategy for answers, and a composite strategy that draws an Exam and then draws answers using the helper. The composite ensures the answers list length matches the exam's answer_key length.

```python
# Helper function to make the following examples terser
def ei_answers_strategy(exam):
    return st.lists(
        st.none() | st.integers(1, 5),
        min_size=len(exam.answer_key),
        max_size=len(exam.answer_key),
    )

@st.composite
def exam_instance_strategy(draw):
    exam = draw(st.from_type(Exam))
    answers = ei_answers_strategy(exam)
    return ExamInstance(student=1, exam=exam, answers=draw(answers))
```

### Example tree with duplicated subtrees

Source: https://github.com/hypothesisworks/hypothesis/blob/master/hypothesis/docs/changelog.rst

```none
                 ┌─────┐
          ┌──────┤  a  ├──────┐
          │      └─────┘      │
       ┌──┴──┐             ┌──┴──┐
       │  b  │             │  a  │
       └──┬──┘             └──┬──┘

### Define rules with initialize and rule decorators

Source: https://github.com/hypothesisworks/hypothesis/blob/master/hypothesis/docs/stateful.rst

Example of a RuleBasedStateMachine that uses initialize to populate bundles and rules to create folders and files. It demonstrates the use of the @initialize and @rule decorators with target and strategy arguments.

```python
import hypothesis.strategies as st
from hypothesis.stateful import Bundle, RuleBasedStateMachine, initialize, rule

name_strategy = st.text(min_size=1).filter(lambda x: "/" not in x)

class NumberModifier(RuleBasedStateMachine):
    folders = Bundle("folders")
    files = Bundle("files")

    @initialize(target=folders)
    def init_folders(self):
        return "/"

    @rule(target=folders, parent=folders, name=name_strategy)
    def create_folder(self, parent, name):
        return f"{parent}/{name}"

    @rule(target=files, parent=folders, name=name_strategy)
    def create_file(self, parent, name):
        return f"{parent}/{name}"
```

### DieHardProblem stateful test with Hypothesis

Source: https://github.com/hypothesisworks/hypothesis/blob/master/website/content/2017-04-05-how-not-to-die-hard-with-hypothesis.md

Defines a RuleBasedStateMachine with rules for filling, emptying, and pouring between 3- and 5-gallon jugs. Uses @settings(max_examples=2000) because the default is not always enough to find a failing example. Invariants check jug capacities and that the big jug never holds exactly 4 gallons.

```python
from hypothesis import note, settings
from hypothesis.stateful import RuleBasedStateMachine, invariant, rule


# The default is not always enough for Hypothesis to find a failing example.
@settings(max_examples=2000)
class DieHardProblem(RuleBasedStateMachine):
    small = 0
    big = 0

    @rule()
    def fill_small(self):
        self.small = 3

    @rule()
    def fill_big(self):
        self.big = 5

    @rule()
    def empty_small(self):
        self.small = 0

    @rule()
    def empty_big(self):
        self.big = 0

    @rule()
    def pour_small_into_big(self):
        old_big = self.big
        self.big = min(5, self.big + self.small)
        self.small = self.small - (self.big - old_big)

    @rule()
    def pour_big_into_small(self):
        old_small = self.small
        self.small = min(3, self.small + self.big)
        self.big = self.big - (self.small - old_small)

    @invariant()
    def physics_of_jugs(self):
        assert 0 <= self.small <= 3
        assert 0 <= self.big <= 5

    @invariant()
    def die_hard_problem_not_solved(self):
        note(f"> small: {self.small} big: {self.big}")
        assert self.big != 4


DieHardTest = DieHardProblem.TestCase
```

### Use precondition to filter rules

    @rule()
    def divide_with_one(self):

### Selection sort implementation in example.py

Source: https://github.com/hypothesisworks/hypothesis/blob/master/hypothesis/docs/tutorial/introduction.rst

Defines a selection sort function that sorts a list by repeatedly extracting the minimum. This is the function under test in the following examples.

```python
# contents of example.py
from hypothesis import given, strategies as st

def selection_sort(lst):
    result = []
    while lst:
        smallest = min(lst)
        result.append(smallest)
        lst.remove(smallest)
    return result
```

### Filter strategy inputs with .filter

### hypothesis.target

Source: https://github.com/hypothesisworks/hypothesis/blob/master/hypothesis/docs/reference/api.rst

The target() function is used to guide input generation towards values that are more likely to falsify a property. It takes a numeric metric and uses it to steer the search.

```APIDOC
## hypothesis.target

### Description
Use this function inside a test to provide a numeric metric that guides input generation towards values that are more likely to falsify the property. This is the core of targeted property-based testing.

### Usage
Call `target(metric)` within a test decorated with `@given`.

### Parameters
- **metric** (float) - Required - The value to maximize or minimize during search.

### Example
```python
from hypothesis import given, strategies as st, target

@given(st.floats(0, 1e100), st.floats(0, 1e100), st.floats(0, 1e100))
def test_associativity_with_target(a, b, c):
    ab_c = (a + b) + c
    a_bc = a + (b + c)
    difference = abs(ab_c - a_bc)
    target(difference)  # Without this, the test almost always passes
    assert difference < 2.0
```

### Define bundles and rules for database comparison

Source: https://github.com/hypothesisworks/hypothesis/blob/master/hypothesis/docs/stateful.rst

Defines two bundles (keys and values) and rules to populate them, save/delete entries, and verify the database matches the model. Uses bundles to encourage reuse of keys and values across operations.

```python
      keys = Bundle("keys")
      values = Bundle("values")

      @rule(target=keys, k=st.binary())
      def add_key(self, k):
          return k

      @rule(target=values, v=st.binary())
      def add_value(self, v):
          return v

      @rule(k=keys, v=values)
      def save(self, k, v):
          self.model[k].add(v)
          self.database.save(k, v)

      @rule(k=keys, v=values)
      def delete(self, k, v):
          self.model[k].discard(v)
          self.database.delete(k, v)

      @rule(k=keys)
      def values_agree(self, k):
          assert set(self.database.fetch(k)) == self.model[k]

      def teardown(self):
          shutil.rmtree(self.tempd)
```

### Test equivalence of sorted() calls with Hypothesis

Source: https://github.com/hypothesisworks/hypothesis/blob/master/hypothesis/tests/ghostwriter/recorded/sorted_self_error_equivalent_1error.txt

Generated by hypothesis.extra.ghostwriter. Uses @given with st.one_of(st.iterables(st.integers()), st.iterables(st.text())), st.none() for key, and st.booleans() for reverse. Calls sorted() twice with identical arguments, asserting equal results or matching exceptions. Uses target(1, label="input was valid") to guide input generation and reject() on ValueError.

```python

# and is provided under the Creative Commons Zero public domain dedication.

import pytest
from hypothesis import given, reject, strategies as st, target


@given(
    iterable=st.one_of(st.iterables(st.integers()), st.iterables(st.text())),
    key=st.none(),
    reverse=st.booleans(),
)
def test_equivalent_sorted_sorted(iterable, key, reverse):
    try:
        result_0_sorted = sorted(iterable, key=key, reverse=reverse)
        exc_type = None
        target(1, label="input was valid")
    except ValueError:
        reject()
    except Exception as exc:
        exc_type = type(exc)

    if exc_type:
        with pytest.raises(exc_type):
            sorted(iterable, key=key, reverse=reverse)
    else:
        result_1_sorted = sorted(iterable, key=key, reverse=reverse)
        assert result_0_sorted == result_1_sorted, (result_0_sorted, result_1_sorted)
```

### ShrinkingTestData class for shrinking byte streams

Source: https://github.com/hypothesisworks/hypothesis/blob/master/website/content/2016-12-10-how-hypothesis-works.md

A TestData implementation used during shrinking. It reads from a fixed byte array and raises StopTest when the requested bytes exceed the available data, which helps limit example size.

```python
class ShrinkingTestData:
    def __init__(self, data):
        self.data = data
        self.index = 0

    def draw_bytes(self, n):
        if self.index + n > len(self.data):
            raise StopTest()
        result = self.data[self.index : self.index + n]
        self.index += n
        return result
```

### Rule-based state machine for heap testing

Source: https://github.com/hypothesisworks/hypothesis/blob/master/website/content/2016-04-19-rule-based-stateful-testing.md

A RuleBasedStateMachine that defines push and pop rules. The pop rule is preconditioned on the heap being non-empty and asserts that the popped value is the minimum. This allows Hypothesis to generate sequences of operations.

```python
from hypothesis.stateful import RuleBasedStateMachine, precondition, rule


class HeapMachine(RuleBasedStateMachine):
    def __init__(self):
        super().__init__()
        self.heap = []

    @rule(value=integers())
    def push(self, value):
        heappush(self.heap, value)

    @rule()
    @precondition(lambda self: self.heap)
    def pop(self):
        correct = min(self.heap)
        result = heappop(self.heap)
        assert correct == result
```

### Implement greedy knapsack packing algorithm

Source: https://github.com/hypothesisworks/hypothesis/blob/master/website/content/2016-05-29-testing-optimizers-with-hypothesis.md

Given items as a list of (value, weight) tuples and a capacity, returns a subset of items with total weight <= capacity. Sorts items by decreasing value per unit weight, breaking ties by lowest weight first, then greedily adds items that fit.

```python
def pack_knapsack(items, capacity):
    """Given items as a list [(value, weight)], with value and weight
    strictly positive integers, try to find a maximum value subset of
    items with total weight <= capacity"""
    remaining_capacity = capacity
    result = []

    # Sort in order of decreasing value per unit weight, breaking
    # ties by taking the lowest weighted items first.
    items = sorted(items, key=lambda x: (x[1] / x[0], x[1]))
    for value, weight in items:
        if weight <= remaining_capacity:
            result.append((value, weight))
            remaining_capacity -= weight
    return result
```

### Naive binary heap implementation

Source: https://github.com/hypothesisworks/hypothesis/blob/master/website/content/2016-04-19-rule-based-stateful-testing.md

A simple binary heap implementation with heapnew, heapempty, heappush, and heappop. The heappop is intentionally incorrect: it returns the smallest element but does not rebalance the heap, leaving it in an invalid state.

```python
def heapnew():
    return []


def heapempty(heap):
    return not heap


def heappush(heap, value):
    heap.append(value)
    index = len(heap) - 1
    while index > 0:
        parent = (index - 1) // 2
        if heap[parent] > heap[index]:
            heap[parent], heap[index] = heap[index], heap[parent]
            index = parent
        else:
            break


def heappop(heap):
    return heap.pop(0)
```

### SearchStrategy and FlatmappedStrategy for chaining strategies

Source: https://github.com/hypothesisworks/hypothesis/blob/master/website/content/2016-12-10-how-hypothesis-works.md

Defines SearchStrategy with a flatmap method that returns a FlatmappedStrategy, which draws a base value and then draws a dependent value using the bind function. This allows chaining strategy definitions where the second draw depends on the first value.

```python
class SearchStrategy:
    def do_draw(self, data):
        raise NotImplementedError()

    def flatmap(self, bind):
        return FlatmappedStrategy(self, bind)


class FlatmappedStrategy(SearchStrategy):
    def __init__(self, base, bind):
        super().__init__()
        self.base = base
        self.bind = bind

    def do_draw(self, data):
        value = data.draw(self.base)
        return data.draw(self.bind(value))
```

### HeapMachine with bundles for heap collection

Source: https://github.com/hypothesisworks/hypothesis/blob/master/website/content/2016-04-19-rule-based-stateful-testing.md

Defines a rule-based state machine using a bundle to manage multiple heaps. Rules create, push, pop, and merge heaps, with a filter on the pop rule to ensure non-empty heaps.

```python
class HeapMachine(RuleBasedStateMachine):
    Heaps = Bundle("heaps")

    @rule(target=Heaps)
    def newheap(self):
        return []

    @rule(heap=Heaps, value=integers())
    def push(self, heap, value):
        heappush(heap, value)

    @rule(heap=Heaps.filter(bool))
    def pop(self, heap):
        correct = min(heap)
        result = heappop(heap)
        assert correct == result

    @rule(target=Heaps, heap1=Heaps, heap2=Heaps)
    def merge(self, heap1, heap2):
        return heapmerge(heap1, heap2)
```

### Int64Strategy with biased distribution

Source: https://github.com/hypothesisworks/hypothesis/blob/master/website/content/2016-12-10-how-hypothesis-works.md

A 64-bit integer strategy that uses a biased distribution to produce integers between 0 and 100 half the time, otherwise uniform bytes. Demonstrates using draw_bytes with a custom distribution.

```python
class Int64Strategy:
    def do_draw(self, data):
        def biased_distribution(random, n):
            if random.randint(0, 1):
                return random.randint(0, 100).to_bytes(n, byteorder="big", signed=False)
            else:
                return uniform(random, n)

        return int.from_bytes(
            data.draw_bytes(8, biased_distribution), byteorder="big", signed=False
        )
```

### Argon2 password hashing test with varying configuration parameters

Source: https://github.com/hypothesisworks/hypothesis/blob/master/website/content/2016-06-13-testing-configuration-parameters.md

Expands the basic test to vary time_cost, parallelism, memory_cost, hash_len, and salt_len. Uses assume() to enforce the constraint parallelism * 8 <= memory_cost. This test found two bugs where a password would not verify against itself.

```python
from argon2 import PasswordHasher

from hypothesis import assume, given, strategies as st


class TestPasswordHasherWithHypothesis:
    @given(
        password=st.text(),
        time_cost=st.integers(1, 10),
        parallelism=st.integers(1, 10),
        memory_cost=st.integers(8, 2048),
        hash_len=st.integers(12, 1000),
        salt_len=st.integers(8, 1000),
    )
    def test_a_password_verifies(
        self,
        password,
        time_cost,
        parallelism,
        memory_cost,
        hash_len,
        salt_len,
    ):
        assume(parallelism * 8 <= memory_cost)
        ph = PasswordHasher(
            time_cost=time_cost,
            parallelism=parallelism,
            memory_cost=memory_cost,
            hash_len=hash_len,
            salt_len=salt_len,
        )
        hash = ph.hash(password)
        assert ph.verify(hash, password)
```

### Unusual loop pattern in engine (while loop)

Source: https://github.com/hypothesisworks/hypothesis/blob/master/guides/internals.rst

This loop is intentionally written in a non-idiomatic way. It increments i only when consider_new_nodes fails, because a successful call changes the shape of the shrink target, altering the loop's length and values. Resetting i on success would cause redundant retries and potentially O(n^2) time.

```python
        i = 0
        while i < len(self.shrink_target.nodes):
            if not self.consider_new_nodes(
                self.shrink_target.nodes[:i] + self.shrink_target.nodes[i + 1 :]
            ):
                i += 1
```

from hypothesis import given

names = (

def test_names_match_our_requirements(name):

### Eris: Test sum commutativity with forAll and then

Source: https://github.com/hypothesisworks/hypothesis/blob/master/website/content/2016-09-04-hypothesis-vs-eris.md

Uses the TestTrait and Generator\int() to define input distributions. The test method body is moved into an anonymous function passed to then(). Uses PHPUnit's assertEquals for assertions.

```php
<?php
use Eris\Generator;
use Eris\TestTrait;

class IntegerTest extends PHPUnit_Framework_TestCase
{
    use TestTrait;

    public function testSumIsCommutative()
    {
        $this
            ->forAll(
                Generator\int(),
                Generator\int()
            )
            ->then(function ($first, $second) {
                $x = $first + $second;
                $y = $second + $first;
                $this->assertEquals(
                    $x,
                    $y,
                    "Sum between {$first} and {$second} should be commutative"
                );
            });
    }

```

### ListStrategy with boolean-terminated elements (good shrinking)

Source: https://github.com/hypothesisworks/hypothesis/blob/master/website/content/2016-12-10-how-hypothesis-works.md

A list strategy that draws elements until a False boolean is drawn. Deleting the byte interval from a True to the end of an element deletes that element, improving shrinking.

```python
class ListStrategy(SearchStrategy):
    def __init__(self, elements):
        super().__init__()
        self.elements = elements

    def do_draw(self, data):
        result = []
        while booleans().do_draw(data):
            result.append(self.elements.do_draw(data))
        return result
```

### Bubble sort reference implementation

Source: https://github.com/hypothesisworks/hypothesis/blob/master/website/content/2016-04-29-testing-performance-optimizations.md

A simple bubble sort implementation used as a reference implementation to test against the merge sort. It is expected to always return the correct sorted list.

```python
def bubble_sort(ls):
    ls = list(ls)
    needs_sorting = True
    while needs_sorting:
        needs_sorting = False
        for i in range(1, len(ls)):
            if ls[i - 1] > ls[i]:
                needs_sorting = True
                ls[i - 1], ls[i] = ls[i], ls[i - 1]
    return ls
```

### Property-based tests for binary search specification

Source: https://github.com/hypothesisworks/hypothesis/blob/master/website/content/2016-06-30-tests-as-complete-specifications.md

Three Hypothesis tests that together specify a left-biased binary search: the returned index is valid, inserting at that index keeps the list sorted, and inserting at any smaller index breaks sortedness. These tests capture the exact specification but may miss low-probability bugs.

```python
from hypothesis import given, strategies as st


@given(lists(integers()).map(sorted), integers())
def test_binary_search_gives_valid_index(ls, v):
    i = binary_search(ls, v)
    assert 0 <= i <= len(ls)


@given(lists(integers()).map(sorted), integers())
def test_inserting_at_binary_search_remains_sorted(ls, v):
    i = binary_search(ls, v)
    ls.insert(i, v)
    assert sorted(ls) == ls


@given(lists(integers()).map(sorted), integers())
def test_inserting_at_smaller_index_gives_unsorted(ls, v):
    for i in range(binary_search(ls, v)):
        ls2 = list(ls)
        ls2.insert(i, v)
        assert sorted(ls2) != ls
```

from hypothesis import assume, given
from hypothesis.strategies import integers

even_numbers = integers().map(lambda x: x * 2)

    assert n % 2 == 0
    assert n <= 4

    original_solution = pack_knapsack(items, capacity)
    assume(original_solution)
    items.append(data.draw(st.sampled_from(original_solution)))
    new_solution = pack_knapsack(items, capacity)

### Flawed binary_search implementation with early return

Source: https://github.com/hypothesisworks/hypothesis/blob/master/website/content/2016-06-30-tests-as-complete-specifications.md

A flawed implementation of binary search that returns early when the pivot equals the value. This violates the smallest-index property, so the third test eventually fails with a counterexample like ls=[0, 1, 1, 1, 1], v=1.

```python
def binary_search(list, value):
    if not list:
        return 0
    if value > list[-1]:
        return len(list)
    if value <= list[0]:
        return 0
    lo = 0
    hi = len(list) - 1
    while lo + 1 < hi:
        mid = (lo + hi) // 2
        pivot = list[mid]
        if value < pivot:
            hi = mid
        elif value == pivot:
            return mid
        else:
            lo = mid
    return hi
```

### Run Length Encoding implementation (encode and decode functions)

Source: https://github.com/hypothesisworks/hypothesis/blob/master/website/content/2016-04-16-encode-decode-invariant.md

A lightly reformatted version of a Run Length Encoding implementation from Rosetta Code. The encode function converts a string into a list of (character, count) tuples, and decode reverses the process. This is the code under test.

```python
def encode(input_string):
    count = 1
    prev = ""
    lst = []
    for character in input_string:
        if character != prev:
            if prev:
                entry = (prev, count)
                lst.append(entry)
            count = 1
            prev = character
        else:
            count += 1
    else:
        entry = (character, count)
        lst.append(entry)
    return lst


def decode(lst):
    q = ""
    for character, count in lst:
        q += character * count
    return q
```

### Corrected heappop implementation

Source: https://github.com/hypothesisworks/hypothesis/blob/master/website/content/2016-04-19-rule-based-stateful-testing.md

A corrected heappop that rebalances the heap after removing the smallest element. It raises ValueError on an empty heap and handles single-element heaps.

```python
def heappop(heap):
    if len(heap) == 0:
        raise ValueError("Empty heap")
    if len(heap) == 1:
        return heap.pop()
    result = heap[0]
    heap[0] = heap.pop()
    index = 0
    while index * 2 + 1 < len(heap):
        children = [index * 2 + 1, index * 2 + 2]
        children = [i for i in children if i < len(heap)]
        assert children
        children.sort(key=lambda x: heap[x])
        for c in children:
            if heap[index] > heap[c]:
                heap[index], heap[c] = heap[c], heap[index]
                index = c
                break
        else:
            break
    return result
```

### Define irv_winner function

Source: https://github.com/hypothesisworks/hypothesis/blob/master/website/content/2016-05-26-exploring-voting-with-hypothesis.md

Implements Instant Runoff Voting (IRV), also known as the Alternative Vote. Runs multiple rounds, eliminating candidates with the lowest score until one remains. Returns the winner or None if no candidate remains.

```python
def irv_winner(election):
    candidates = candidates_for_election(election)
    while len(candidates) > 1:
        scores = Counter()
        for vote in election:
            for c in vote:
                if c in candidates:
                    scores[c] += 1
                    break
        losing_score = min(scores[c] for c in candidates)
        candidates = [c for c in candidates if scores[c] > losing_score]
    if not candidates:
        return None
    else:
        return candidates[0]
```

### Merge sort implementation with incomplete merge_sorted_lists

Source: https://github.com/hypothesisworks/hypothesis/blob/master/website/content/2016-04-29-testing-performance-optimizations.md

A merge sort implementation with a helper that merges two sorted lists. The merge_sorted_lists function is intentionally incomplete (it drops leftover elements) to illustrate a bug that property-based testing can catch.

```python
def merge_sort(ls):
    if len(ls) <= 1:
        return ls
    else:
        k = len(ls) // 2
        return merge_sorted_lists(merge_sort(ls[:k]), merge_sort(ls[k:]))


def merge_sorted_lists(x, y):
    result = []
    i = 0
    j = 0
    while i < len(x) and j < len(y):
        if x[i] <= y[j]:
            result.append(x[i])
            i += 1
        else:
            result.append(y[j])
            j += 1
    return result
```

### Hard-to-shrink loop vs easy-to-shrink loop

Source: https://github.com/hypothesisworks/hypothesis/blob/master/guides/strategies-that-shrink.rst

Compares two loop forms for drawing values. The first (for loop with n) is hard to shrink because it requires reducing n and deleting something simultaneously. The second (while loop with draw) is easier because the shrinker can delete one iteration without touching anything else.

```python
# This form of loop is hard to shrink, because we'd have to reduce `n` and
# delete something in the loop simultaneously.  It's equivalent to the
# `.flatmap` example above.  We _do_ shrink this, but much more slowly.
n = draw(integers(0, 10))
for _ in range(n):
    ...
    draw(...)
    ...

# In this form, the shrinker can see a repeated structure of labels
# and delete one loop iteration without touching anything else.
# We use a variant of this trick to generate collections internally!
while draw(integers(0, x)) > threshold:
    ...
    draw(...)
    ...
```

### GeneratingTestData subclass recording drawn bytes

Source: https://github.com/hypothesisworks/hypothesis/blob/master/website/content/2016-12-10-how-hypothesis-works.md

A TestData subclass that draws bytes from a distribution, records them, and raises StopTest when the maximum byte limit is exceeded. This recording enables replaying the test afterwards.

```python
class GeneratingTestData(TestData):
    def __init__(self, random, max_bytes):
        self.max_bytes = max_bytes
        self.random = random
        self.record = bytearray()

    def draw_bytes(self, n, distribution):
        if n + len(self.record) > self.max_bytes:
            raise StopTest()
        result = distribution(self.random, n)
        self.record.extend(result)
        return result
```

### Test numpy.matmul GUFunc with Hypothesis

Source: https://github.com/hypothesisworks/hypothesis/blob/master/hypothesis/tests/ghostwriter/recorded/magic_gufunc.txt

Generated by hypothesis.extra.ghostwriter. Uses mutually_broadcastable_shapes with signature "(n?,k),(k,m?)->(n?,m?)" and samples dtypes from numpy.matmul.types excluding those containing 'O'. Draws arrays with allow_nan=True and asserts result shape and dtype char.

```python
# This test code was written by the `hypothesis.extra.ghostwriter` module
# and is provided under the Creative Commons Zero public domain dedication.

import numpy
from hypothesis import given, strategies as st
from hypothesis.extra.numpy import arrays, mutually_broadcastable_shapes


@given(
    data=st.data(),
    shapes=mutually_broadcastable_shapes(signature="(n?,k),(k,m?)->(n?,m?)"),
    types=st.sampled_from([sig for sig in numpy.matmul.types if "O" not in sig]),
)
def test_gufunc_matmul(data, shapes, types):
    input_shapes, expected_shape = shapes
    input_dtypes, expected_dtype = types.split("->")
    array_strats = [
        arrays(dtype=dtp, shape=shp, elements={"allow_nan": True})
        for dtp, shp in zip(input_dtypes, input_shapes)
    ]

    a, b = data.draw(st.tuples(*array_strats))
    result = numpy.matmul(a, b)

    assert result.shape == expected_shape
    assert result.dtype.char == expected_dtype
```

### Define plurality_winner function

Source: https://github.com/hypothesisworks/hypothesis/blob/master/website/content/2016-05-26-exploring-voting-with-hypothesis.md

Implements plurality voting: the candidate with the most first-preference votes wins. Takes a list of votes (each a list of candidates in order) and returns the winner or None in case of a tie.

```python
def plurality_winner(election):
    counts = Counter(vote[0] for vote in election)
    alternatives = candidates_for_election(election)
    winning_score = max(counts.values())
    winners = [c for c, v in counts.items() if v == winning_score]
    if len(winners) > 1:
        return None
    else:
        return winners[0]
```

### Fixed merge_sorted_lists with leftover handling

Source: https://github.com/hypothesisworks/hypothesis/blob/master/website/content/2016-04-29-testing-performance-optimizations.md

Corrected version of merge_sorted_lists that appends any leftover elements from the input lists. After this fix, the Hypothesis test passes.

```python
def merge_sorted_lists(x, y):
    result = []
    i = 0
    j = 0
    while i < len(x) and j < len(y):
        if x[i] <= y[j]:
            result.append(x[i])
            i += 1
        else:
            result.append(y[j])
            j += 1
    result.extend(x[i:])
    result.extend(y[j:])
    return result
```

### Broken encode with missing count reset

Source: https://github.com/hypothesisworks/hypothesis/blob/master/website/content/2016-04-16-encode-decode-invariant.md

def encode(input_string):
    if not input_string:
        return []
    count = 1
    prev = ""
    lst = []
    for character in input_string:

            if prev:

### Suppress function_scoped_fixture health check

Source: https://github.com/hypothesisworks/hypothesis/blob/master/website/content/2016-08-09-hypothesis-pytest-fixtures.md

Use this pattern when a test uses a function-scoped pytest fixture with Hypothesis. The @settings decorator suppresses the HealthCheck.function_scoped_fixture to avoid the health check error, allowing the test to run.

```python
from hypothesis import HealthCheck, given, settings, strategies as st


@settings(suppress_health_check=[HealthCheck.function_scoped_fixture])
@given(a=st.none())
def test_stuff(a, stuff):
    assert a is None
```
