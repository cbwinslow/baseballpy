df_duckdb = duckdb.sql("SELECT * FROM df_polars")

### Type Hints Usage Example

Source: https://github.com/narwhals-dev/narwhals/blob/main/docs/api-reference/typing.md

Example demonstrating how to use type hints from narwhals.typing with nw.from_native and nw.narwhalify, and the resulting type inference behavior.

```APIDOC
## Type Hints Usage Example

### Description
Demonstrates the use of type hints from `narwhals.typing` with `nw.from_native` and `nw.narwhalify`, showing how type inference differs between the two approaches.

### Code Example
```py
import polars as pl
import narwhals as nw
from narwhals.typing import IntoDataFrameT, DataFrameT

df = pl.DataFrame({"a": [1, 2, 3]})


def func(df_native: IntoDataFrameT) -> IntoDataFrameT:
    df = nw.from_native(df_native, eager_only=True)
    return df.select(b=nw.col("a")).to_native()


reveal_type(func(df))


@nw.narwhalify(strict=True)
def func_2(df: DataFrameT) -> DataFrameT:
    return df.select(b=nw.col("a"))


reveal_type(func_2(df))
```

### Expected mypy Output
```console
$ mypy t.py
t.py:13: note: Revealed type is "polars.dataframe.frame.DataFrame"
t.py:21: note: Revealed type is "Any"
Success: no issues found in 1 source file
```

### Notes
- `nw.from_native` preserves type hints better than `nw.narwhalify`.
- Type hints are respected inside the function body when arguments are typed.
```

### Example: Using nw.from_native vs nw.narwhalify for type hints

Source: https://github.com/narwhals-dev/narwhals/blob/main/docs/api-reference/typing.md

This example shows two functions: one using `nw.from_native` and one using `@nw.narwhalify`. The mypy output reveals that `nw.from_native` preserves the concrete type (`polars.DataFrame`) while `nw.narwhalify` results in `Any`. Use `nw.from_native` and `nw.to_native` to preserve type hints as much as possible.

```python
import polars as pl
import narwhals as nw
from narwhals.typing import IntoDataFrameT, DataFrameT

df = pl.DataFrame({"a": [1, 2, 3]})


def func(df_native: IntoDataFrameT) -> IntoDataFrameT:
    df = nw.from_native(df_native, eager_only=True)
    return df.select(b=nw.col("a")).to_native()


reveal_type(func(df))


@nw.narwhalify(strict=True)
def func_2(df: DataFrameT) -> DataFrameT:
    return df.select(b=nw.col("a"))


reveal_type(func_2(df))
```

### Generate SQL from DuckDB using narwhals.sql

Source: https://github.com/narwhals-dev/narwhals/blob/main/docs/generating_sql.md

Creates a table named 'prices' with date and price columns, applies the same aggregation, and prints the generated SQL. Requires DuckDB to be installed.

```python
import narwhals as nw
from narwhals.sql import table

prices = table("prices", {"date": nw.Date, "price": nw.Float64})

result = (
    prices.group_by(nw.col("date").dt.truncate("1mo"))
    .agg(nw.col("price").mean())
    .sort("date")
)
print(result.to_sql())
```

### Simple dataframe-agnostic function example (t.py)

Source: https://github.com/narwhals-dev/narwhals/blob/main/docs/installation.md

Creates a Python file t.py with a function that returns column names from a native dataframe. It imports pandas, Polars, PyArrow, and Narwhals, and prints outputs for each library. Run with `python t.py`.

```python
from __future__ import annotations

import pandas as pd
import polars as pl
import pyarrow as pa
import narwhals as nw
from narwhals.typing import IntoFrame


def agnostic_get_columns(df_native: IntoFrame) -> list[str]:
    df = nw.from_native(df_native)
    column_names = df.columns
    return column_names


data = {"a": [1, 2, 3], "b": [4, 5, 6]}
df_pandas = pd.DataFrame(data)
df_polars = pl.DataFrame(data)
table_pa = pa.table(data)

print("pandas output")
print(agnostic_get_columns(df_pandas))

print("Polars output")
print(agnostic_get_columns(df_polars))

print("PyArrow output")
print(agnostic_get_columns(table_pa))
```

### Define multiplication function for null preservation example

Source: https://github.com/narwhals-dev/narwhals/blob/main/docs/concepts/boolean.md

Defines a function that multiplies column 'a' by 2, preserving nulls. Used in the null preservation example across pandas, Polars, and PyArrow.

```python
import narwhals as nw
from narwhals.typing import IntoDataFrameT, IntoLazyFrameT

data = {"a": [1.4, None, 4.2]}


def multiplication(
    df: IntoDataFrameT | IntoLazyFrameT,
) -> IntoDataFrameT | IntoLazyFrameT:
    return nw.from_native(df).with_columns((nw.col("a") * 2).alias("a*2")).to_native()
```

### Define a dataframe-agnostic function avg_monthly_price

Source: https://github.com/narwhals-dev/narwhals/blob/main/docs/generating_sql.md

Defines a function that groups by month, computes the mean price, and sorts by date. This function is used in later examples to generate SQL.

```python
import narwhals as nw
from narwhals.typing import FrameT


def avg_monthly_price(df: FrameT) -> FrameT:
    return (
        df.group_by(nw.col("date").dt.truncate("1mo"))
        .agg(nw.col("price").mean())
        .sort("date")
    )
```

Creates a PandasLikeDataFrame from a pandas DataFrame, builds an expression (col('a') + 1), and calls its _call method to get a sequence of series. Shows the native series of the first result.

```python
import narwhals as nw
from narwhals._pandas_like.namespace import PandasLikeNamespace
from narwhals._pandas_like.dataframe import PandasLikeDataFrame

import pandas as pd

pn = PandasLikeNamespace(implementation=Implementation.PANDAS, version=Version.MAIN)

df_pd = pd.DataFrame({"a": [1, 2, 3], "b": [4, 5, 6]})
df = PandasLikeDataFrame(
    df_pd,
    implementation=Implementation.PANDAS,
    version=Version.MAIN,
    validate_column_names=True,
)
expression = pn.col("a") + 1
result = expression._call(df)
print(f"length of result: {len(result)}\n")
print("native series of first value of result: ")
print([x.native for x in result][0])
```

### Fit method using from/to_native with eager_only=True

Source: https://github.com/narwhals-dev/narwhals/blob/main/docs/basics/complete_example.md

### Complete StandardScaler using from/to_native

Source: https://github.com/narwhals-dev/narwhals/blob/main/docs/basics/complete_example.md

Full implementation of the StandardScaler class with fit and transform methods using nw.from_native and to_native. The fit method uses eager_only=True to compute means and standard deviations.

```python
from typing import Self
import narwhals as nw
from narwhals.typing import IntoDataFrameT
from narwhals.typing import IntoLazyFrameT


class StandardScaler:
    def fit(self, df: IntoDataFrameT) -> Self:
        df_nw = nw.from_native(df, eager_only=True)
        self._means = {col: df_nw[col].mean() for col in df_nw.columns}
        self._std_devs = {col: df_nw[col].std() for col in df_nw.columns}
        self._columns = df_nw.columns
        return self

    def transform(
        self, df: IntoDataFrameT | IntoLazyFrameT
    ) -> IntoDataFrameT | IntoLazyFrameT:
        df_nw = nw.from_native(df)
        return df_nw.with_columns(
            (nw.col(col) - self._means[col]) / self._std_devs[col]
            for col in self._columns
        ).to_native()
```

### Approach 2: Efficient group-by with precomputed column

Source: https://github.com/narwhals-dev/narwhals/blob/main/docs/concepts/improve_group_by_operation.md

This approach computes the new column first, then performs a simple aggregation, avoiding the UserWarning and improving performance.

```python
import narwhals as nw
import pandas as pd
from narwhals.typing import IntoDataFrameT, IntoLazyFrameT

data = {"a": [1, 2, 3, 4, 5], "b": [5, 4, 3, 2, 1], "c": [10, 20, 30, 40, 50]}

df_pd = pd.DataFrame(data)


def approach_2(
    df_native: IntoDataFrameT | IntoLazyFrameT,
) -> IntoDataFrameT | IntoLazyFrameT:
    df = nw.from_native(df_native)
    df = df.with_columns(d=nw.col("b") + nw.col("c")).group_by("a").agg(nw.sum("d"))
    return df.to_native()


print(approach_2(df_pd))
```

### Complete StandardScaler using @narwhalify

Source: https://github.com/narwhals-dev/narwhals/blob/main/docs/basics/complete_example.md

Full implementation of the StandardScaler class using @nw.narwhalify decorators. The fit method uses eager_only=True, while transform does not, allowing lazy dataframes to stay lazy.

```python
from typing import Self
import narwhals as nw
from narwhals.typing import DataFrameT
from narwhals.typing import FrameT


class StandardScaler:
    @nw.narwhalify(eager_only=True)
    def fit(self, df: DataFrameT) -> Self:
        self._means = {col: df[col].mean() for col in df.columns}
        self._std_devs = {col: df[col].std() for col in df.columns}
        self._columns = df.columns
        return self

    @nw.narwhalify
    def transform(self, df: FrameT) -> FrameT:
        return df.with_columns(
            (nw.col(col) - self._means[col]) / self._std_devs[col]
            for col in self._columns
        )
```

import narwhals.stable.v2 as nw

### StandardScaler transform using from/to_native

Source: https://github.com/narwhals-dev/narwhals/blob/main/docs/basics/complete_example.md

Implements the transform method using nw.from_native and to_native to accept either eager or lazy dataframes. The method computes standardized columns using precomputed means and standard deviations.

```python
from typing import Self
import narwhals as nw
from narwhals.typing import IntoDataFrameT, IntoLazyFrameT


class StandardScaler:
    ...

    def transform(
        self, df: IntoDataFrameT | IntoLazyFrameT
    ) -> IntoDataFrameT | IntoLazyFrameT:
        df_nw = nw.from_native(df)
        return df_nw.with_columns(
            (nw.col(col) - self._means[col]) / self._std_devs[col]
            for col in self._columns
        ).to_native()
```

import narwhals as nw
from narwhals.typing import FrameT

        a_sum=nw.col("a").sum(), a_mean=nw.col("a").mean(), a_std=nw.col("a").std()
    )

### Define a dataframe-agnostic function with Narwhals

Source: https://github.com/narwhals-dev/narwhals/blob/main/README.md

Shows how to wrap a native dataframe with from_native, use the Polars API subset (with_columns, when, col, lit), and convert back with to_native. The function accepts any supported dataframe type and returns the same type.

```python
import narwhals as nw
from narwhals.typing import IntoDataFrameT, IntoLazyFrameT


def agnostic_function(
    df_native: IntoDataFrameT | IntoLazyFrameT,
) -> IntoDataFrameT | IntoLazyFrameT:
    return (
        nw.from_native(df_native)
        .with_columns(
            category=nw.when(nw.col("animal").str.contains("whale"))
            .then(nw.lit("whale"))
            .otherwise(nw.lit("other"))
        )
        .to_native()
    )
```

### Approach 1: Complex group-by expression causing UserWarning

Source: https://github.com/narwhals-dev/narwhals/blob/main/docs/concepts/improve_group_by_operation.md

This approach uses a complex expression inside agg, which translates to pandas apply and triggers the UserWarning. It is inefficient and should be avoided.

```python
import narwhals as nw
import pandas as pd
from narwhals.typing import IntoDataFrameT, IntoLazyFrameT

data = {"a": [1, 2, 3, 4, 5], "b": [5, 4, 3, 2, 1], "c": [10, 20, 30, 40, 50]}

df_pd = pd.DataFrame(data)


def approach_1(
    df_native: IntoDataFrameT | IntoLazyFrameT,
) -> IntoDataFrameT | IntoLazyFrameT:
    df = nw.from_native(df_native)
    df = df.group_by("a").agg(d=(nw.col("b") + nw.col("c")).sum())
    return df.to_native()


print(approach_1(df_pd))
```

### StandardScaler transform using @narwhalify

Source: https://github.com/narwhals-dev/narwhals/blob/main/docs/basics/complete_example.md

Implements the transform method using the @nw.narwhalify decorator, which automatically converts the input and output dataframes. The method operates directly on the Narwhals dataframe.

```python
from typing import Self
import narwhals as nw
from narwhals.typing import FrameT


class StandardScaler:
    ...

    @nw.narwhalify
    def transform(self, df: FrameT) -> FrameT:
        return df.with_columns(
            (nw.col(col) - self._means[col]) / self._std_devs[col]
            for col in self._columns
        )
```

The Expr class represents an expression that can be used for lazy and eager computation on dataframe columns. It provides a wide range of methods for data transformation, aggregation, and window operations.

```APIDOC
# narwhals.Expr

## Overview

The `narwhals.Expr` class represents an expression in the Narwhals dataframe library. Expressions are used to define computations on dataframe columns, supporting both lazy and eager evaluation. This class provides methods for arithmetic, aggregation, window functions, and data cleaning.

## Methods

### LazyGroupBy.agg

Source: https://github.com/narwhals-dev/narwhals/blob/main/docs/api-reference/lazy_group_by.md

The agg method is used to define aggregations on a LazyGroupBy object. It accepts one or more expressions or strings specifying the aggregations to compute.

```APIDOC
## LazyGroupBy.agg

### Description
Defines aggregations to apply to the grouped data in a lazy group-by operation.

### Method
agg

### Signature
agg(*exprs)

### Parameters
- **exprs** (expression or str) - Required - One or more expressions or column names specifying the aggregations to compute.

### Returns
- LazyFrame - A new LazyFrame with the aggregated results.

### Example
```python
import narwhals as nw

df = nw.from_dict({"a": [1, 1, 2], "b": [4, 5, 6]})
result = df.group_by("a").agg(nw.col("b").sum())
```

### Datetime and Duration dtype hashing behavior

Source: https://github.com/narwhals-dev/narwhals/blob/main/docs/backcompat.md

Since Narwhals 1.9.0, Datetime and Duration dtypes hash using both time_unit and time_zone. The v1 behavior treats Datetime("us") as equal to Datetime, while the main namespace does not.

```python
import narwhals.stable.v1 as nw_v1
import narwhals as nw

# v1 behaviour:
assert nw_v1.Datetime("us") in {nw_v1.Datetime}

# main namespace (and, when we get there, v2) behaviour:
assert nw.Datetime("us") not in {nw.Datetime}
assert nw.Datetime("us") in {nw.Datetime("us")}
```
