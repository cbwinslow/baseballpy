### Configure separate httpx and httpcore loggers with logging.config.dictConfig

Source: https://github.com/encode/httpx/blob/master/docs/logging.md

Use dictionary configuration for advanced logging setups requiring independent configuration of the 'httpx' and 'httpcore' loggers. Handlers and formatters are defined to direct formatted log output to standard error.

```python
import logging.config
import httpx

LOGGING_CONFIG = {
    "version": 1,
    "handlers": {
        "default": {
            "class": "logging.StreamHandler",
            "formatter": "http",
            "stream": "ext://sys.stderr"
        }
    },
    "formatters": {
        "http": {
            "format": "%(levelname)s [%(asctime)s] %(name)s - %(message)s",
            "datefmt": "%Y-%m-%d %H:%M:%S",
        }
    },
    'loggers': {
        'httpx': {
            'handlers': ['default'],
            'level': 'DEBUG',
        },
        'httpcore': {
            'handlers': ['default'],
            'level': 'DEBUG',
        },
    }
}

logging.config.dictConfig(LOGGING_CONFIG)
httpx.get('https://www.example.com')
```

### Configure character set auto-detection using chardet

Source: https://github.com/encode/httpx/blob/master/docs/advanced/text-encodings.md

Install chardet and provide a callable to default_encoding that accepts response content bytes and returns the detected encoding. The auto-detection function is invoked when no charset is supplied in the response headers.

```shell
$ pip install httpx
$ pip install chardet
```

```python
import httpx
import chardet

def autodetect(content):
    return chardet.detect(content).get("encoding")

# Using a client with character-set autodetection enabled.
client = httpx.Client(default_encoding=autodetect)
response = client.get(...)
print(response.encoding)  # This will either print the charset given in
                          # the Content-Type charset, or else the auto-detected
                          # character set.
print(response.text)
```

### Configure complex proxy routing across domains and schemes using mounts

Source: https://github.com/encode/httpx/blob/master/docs/advanced/transports.md

Combine routing rules in a mounts dictionary to send requests through distinct proxies or bypass proxies based on scheme, domain, subdomain wildcards, and ports.

```python
mounts = {
    # Route all traffic through a proxy by default...
    "all://": httpx.HTTPTransport(proxy="http://localhost:8030"),
    # But don't use proxies for HTTPS requests to "domain.io"...
    "https://domain.io": None,
    # And use another proxy for requests to "example.com" and its subdomains...
    "all://*example.com": httpx.HTTPTransport(proxy="http://localhost:8031"),
    # And yet another proxy if HTTP is used,
    # and the "internal" subdomain on port 5550 is requested...
    "http://internal.example.com:5550": httpx.HTTPTransport(proxy="http://localhost:8032"),
}
```

### Round-robin requests across multiple proxies

Source: https://github.com/encode/httpx/blob/master/docs/advanced/transports.md

Cycles through a list of proxy configurations using httpx.Proxy and httpx.HTTPTransport instances on each request.

```python
class ProxyRoundRobin(httpx.BaseTransport):
    def __init__(self, proxies, **kwargs):
        self._transports = [
            httpx.HTTPTransport(proxy=proxy, **kwargs)
            for proxy in proxies
        ]
        self._idx = 0

    def handle_request(self, request):
        transport = self._transports[self._idx]
        self._idx = (self._idx + 1) % len(self._transports)
        return transport.handle_request(request)

    def close(self):
        for transport in self._transports:
            transport.close()

proxies = [
    httpx.Proxy("http://127.0.0.1:8081"),
    httpx.Proxy("http://127.0.0.1:8082"),
    httpx.Proxy("http://127.0.0.1:8083"),
]
transport = ProxyRoundRobin(proxies=proxies)
client = httpx.Client(transport=transport)
```

### Monitor download progress using tqdm

Source: https://github.com/encode/httpx/blob/master/docs/advanced/clients.md

Stream response bytes and update a tqdm progress bar using response.num_bytes_downloaded to accurately track raw downloaded content length.

```python
import tempfile

import httpx
from tqdm import tqdm

with tempfile.NamedTemporaryFile() as download_file:
    url = "https://speed.hetzner.de/100MB.bin"
    with httpx.stream("GET", url) as response:
        total = int(response.headers["Content-Length"])

        with tqdm(total=total, unit_scale=True, unit_divisor=1024, unit="B") as progress:
            num_bytes_downloaded = response.num_bytes_downloaded
            for chunk in response.iter_bytes():
                download_file.write(chunk)
                progress.update(response.num_bytes_downloaded - num_bytes_downloaded)
                num_bytes_downloaded = response.num_bytes_downloaded
```

### Monitor download progress using rich

import rich.progress

    url = "https://speed.hetzner.de/100MB.bin"
    with httpx.stream("GET", url) as response:
        total = int(response.headers["Content-Length"])

        with rich.progress.Progress(
            "[progress.percentage]{task.percentage:>3.0f}%",
            rich.progress.BarColumn(bar_width=None),
            rich.progress.DownloadColumn(),
            rich.progress.TransferSpeedColumn(),

            for chunk in response.iter_bytes():
                download_file.write(chunk)
                progress.update(download_task, completed=response.num_bytes_downloaded)
```

Uses multiple yields in auth_flow to inspect the response status and resend the request with authentication headers if a 401 response is received.

```python

    def __init__(self, token):
        self.token = token

    def auth_flow(self, request):
      response = yield request
      if response.status_code == 401:

          # with a custom `X-Authentication` header.
          request.headers['X-Authentication'] = self.token
          yield request

### Wrap HTTPTransport for request and response debugging

### Redirect HTTP requests using a custom BaseTransport

Source: https://github.com/encode/httpx/blob/master/docs/advanced/transports.md

Mount a custom transport inheriting from BaseTransport to redirect outgoing HTTP requests to HTTPS.

```python
import httpx

class HTTPSRedirectTransport(httpx.BaseTransport):
    """
    A transport that always redirects to HTTPS.
    """

    def handle_request(self, method, url, headers, stream, extensions):
        scheme, host, port, path = url
        if port is None:
            location = b"https://%s%s" % (host, path)
        else:
            location = b"https://%s:%d%s" % (host, port, path)
        stream = httpx.ByteStream(b"")
        headers = [(b"location", location)]
        extensions = {}
        return 303, headers, stream, extensions


# A client where any `http` requests are always redirected to `https`
mounts = {'http://': HTTPSRedirectTransport()}
client = httpx.Client(mounts=mounts)
```

### Round-robin requests across multiple proxies

Source: https://github.com/encode/httpx/blob/master/docs/advanced/transports.md

Cycles through a list of proxy configurations using httpx.Proxy and httpx.HTTPTransport instances on each request.

```python
class ProxyRoundRobin(httpx.BaseTransport):
    def __init__(self, proxies, **kwargs):
        self._transports = [
            httpx.HTTPTransport(proxy=proxy, **kwargs)
            for proxy in proxies
        ]
        self._idx = 0

    def handle_request(self, request):
        transport = self._transports[self._idx]
        self._idx = (self._idx + 1) % len(self._transports)
        return transport.handle_request(request)

    def close(self):
        for transport in self._transports:
            transport.close()

proxies = [
    httpx.Proxy("http://127.0.0.1:8081"),
    httpx.Proxy("http://127.0.0.1:8082"),
    httpx.Proxy("http://127.0.0.1:8083"),
]

```

### Wrap HTTPTransport for request and response debugging

Source: https://github.com/encode/httpx/blob/master/docs/advanced/transports.md

Wraps httpx.HTTPTransport to inspect or log requests and responses. Pass kwargs to the underlying transport and forward the close method call.

```python
class DebuggingTransport(httpx.BaseTransport):
    def __init__(self, **kwargs):
        self._wrapper = httpx.HTTPTransport(**kwargs)

    def handle_request(self, request):
        print(f">>> {request}")
        response = self._wrapper.handle_request(request)
        print(f"<<< {response}")
        return response

    def close(self):
        self._wrapper.close()

transport = DebuggingTransport()
client = httpx.Client(transport=transport)
```

### Redirect HTTP requests using a custom BaseTransport

Source: https://github.com/encode/httpx/blob/master/docs/advanced/transports.md

Mount a custom transport inheriting from BaseTransport to redirect outgoing HTTP requests to HTTPS.

```python
import httpx

class HTTPSRedirectTransport(httpx.BaseTransport):
    """
    A transport that always redirects to HTTPS.
    """

    def handle_request(self, method, url, headers, stream, extensions):
        scheme, host, port, path = url
        if port is None:
            location = b"https://%s%s" % (host, path)
        else:
            location = b"https://%s:%d%s" % (host, port, path)
        stream = httpx.ByteStream(b"")
        headers = [(b"location", location)]
        extensions = {}
        return 303, headers, stream, extensions


# A client where any `http` requests are always redirected to `https`
mounts = {'http://': HTTPSRedirectTransport()}
client = httpx.Client(mounts=mounts)
```

### Bypass Standard Path Escaping with target Extension

Source: https://github.com/encode/httpx/blob/master/docs/advanced/extensions.md

Overrides the HTTP request target to send unescaped or non-standard characters directly in the HTTP request line. Targets must still form valid HTTP requests; invalid syntax such as whitespace raises a `LocalProtocolError`.

```python

# connect to "www.example.com" and send an HTTP/1.1 request like...
#
# GET /test%5Epath HTTP/1.1
#
# Using the target extension we can include the literal '^'...
#
# GET /test^path HTTP/1.1
#
# Note that requests must still be valid HTTP requests.
# For example including whitespace in the target will raise a `LocalProtocolError`.
extensions = {"target": b"/test^path"}
response = httpx.get("https://www.example.com", extensions=extensions)
```

### Implement a multi-step custom Auth subclass with retry on 401

Source: https://github.com/encode/httpx/blob/master/docs/advanced/authentication.md

Uses multiple yields in auth_flow to inspect the response status and resend the request with authentication headers if a 401 response is received.

```python
class MyCustomAuth(httpx.Auth):
    def __init__(self, token):
        self.token = token

    def auth_flow(self, request):
      response = yield request
      if response.status_code == 401:
          # If the server issues a 401 response then resend the request,
          # with a custom `X-Authentication` header.
          request.headers['X-Authentication'] = self.token
          yield request
```

### Monitor download progress using tqdm

Source: https://github.com/encode/httpx/blob/master/docs/advanced/clients.md

Stream response bytes and update a tqdm progress bar using response.num_bytes_downloaded to accurately track raw downloaded content length.

```python
import tempfile

import httpx
from tqdm import tqdm

with tempfile.NamedTemporaryFile() as download_file:
    url = "https://speed.hetzner.de/100MB.bin"
    with httpx.stream("GET", url) as response:
        total = int(response.headers["Content-Length"])

        with tqdm(total=total, unit_scale=True, unit_divisor=1024, unit="B") as progress:
            num_bytes_downloaded = response.num_bytes_downloaded
            for chunk in response.iter_bytes():
                download_file.write(chunk)
                progress.update(response.num_bytes_downloaded - num_bytes_downloaded)
                num_bytes_downloaded = response.num_bytes_downloaded
```

### Monitor download progress using rich

        with rich.progress.Progress(
            "[progress.percentage]{task.percentage:>3.0f}%",
            rich.progress.BarColumn(bar_width=None),

### Monitor download progress using tqdm

### Round-robin requests across multiple proxies

Source: https://github.com/encode/httpx/blob/master/docs/advanced/transports.md

Cycles through a list of proxy configurations using httpx.Proxy and httpx.HTTPTransport instances on each request.

```python
class ProxyRoundRobin(httpx.BaseTransport):
    def __init__(self, proxies, **kwargs):
        self._transports = [
            httpx.HTTPTransport(proxy=proxy, **kwargs)
            for proxy in proxies
        ]
        self._idx = 0

    def handle_request(self, request):
        transport = self._transports[self._idx]
        self._idx = (self._idx + 1) % len(self._transports)
        return transport.handle_request(request)

    def close(self):
        for transport in self._transports:
            transport.close()

proxies = [
    httpx.Proxy("http://127.0.0.1:8081"),
    httpx.Proxy("http://127.0.0.1:8082"),
    httpx.Proxy("http://127.0.0.1:8083"),
]
transport = ProxyRoundRobin(proxies=proxies)
client = httpx.Client(transport=transport)
```

- `def aclose()` -> **None**
- `def anext()` -> **Response**

### Redirect HTTP requests using a custom BaseTransport

Source: https://github.com/encode/httpx/blob/master/docs/advanced/transports.md

Mount a custom transport inheriting from BaseTransport to redirect outgoing HTTP requests to HTTPS.

```python
import httpx

class HTTPSRedirectTransport(httpx.BaseTransport):
    """
    A transport that always redirects to HTTPS.
    """

    def handle_request(self, method, url, headers, stream, extensions):
        scheme, host, port, path = url
        if port is None:
            location = b"https://%s%s" % (host, path)
        else:
            location = b"https://%s:%d%s" % (host, port, path)
        stream = httpx.ByteStream(b"")
        headers = [(b"location", location)]
        extensions = {}
        return 303, headers, stream, extensions


# A client where any `http` requests are always redirected to `https`
mounts = {'http://': HTTPSRedirectTransport()}
client = httpx.Client(mounts=mounts)
```

### Bypass Standard Path Escaping with target Extension

### Round-robin requests across multiple proxies

Source: https://github.com/encode/httpx/blob/master/docs/advanced/transports.md

Cycles through a list of proxy configurations using httpx.Proxy and httpx.HTTPTransport instances on each request.

```python
class ProxyRoundRobin(httpx.BaseTransport):
    def __init__(self, proxies, **kwargs):
        self._transports = [
            httpx.HTTPTransport(proxy=proxy, **kwargs)
            for proxy in proxies
        ]
        self._idx = 0

    def handle_request(self, request):
        transport = self._transports[self._idx]
        self._idx = (self._idx + 1) % len(self._transports)
        return transport.handle_request(request)

    def close(self):
        for transport in self._transports:
            transport.close()

proxies = [
    httpx.Proxy("http://127.0.0.1:8081"),
    httpx.Proxy("http://127.0.0.1:8082"),

### Monitor download progress using tqdm

Source: https://github.com/encode/httpx/blob/master/docs/advanced/clients.md

Stream response bytes and update a tqdm progress bar using response.num_bytes_downloaded to accurately track raw downloaded content length.

```python
import tempfile

import httpx
from tqdm import tqdm

with tempfile.NamedTemporaryFile() as download_file:
    url = "https://speed.hetzner.de/100MB.bin"
    with httpx.stream("GET", url) as response:
        total = int(response.headers["Content-Length"])

        with tqdm(total=total, unit_scale=True, unit_divisor=1024, unit="B") as progress:
            num_bytes_downloaded = response.num_bytes_downloaded
            for chunk in response.iter_bytes():
                download_file.write(chunk)
                progress.update(response.num_bytes_downloaded - num_bytes_downloaded)
                num_bytes_downloaded = response.num_bytes_downloaded
```

### Monitor download progress using rich

Source: https://github.com/encode/httpx/blob/master/docs/advanced/clients.md

```python
import tempfile
import httpx
import rich.progress

with tempfile.NamedTemporaryFile() as download_file:

        total = int(response.headers["Content-Length"])

        with rich.progress.Progress(
            "[progress.percentage]{task.percentage:>3.0f}%",
            rich.progress.BarColumn(bar_width=None),
            rich.progress.DownloadColumn(),

        ) as progress:
            download_task = progress.add_task("Download", total=total)

```

### Wrap HTTPTransport for request and response debugging

### Redirect HTTP requests using a custom BaseTransport

Source: https://github.com/encode/httpx/blob/master/docs/advanced/transports.md

Mount a custom transport inheriting from BaseTransport to redirect outgoing HTTP requests to HTTPS.

```python
import httpx

class HTTPSRedirectTransport(httpx.BaseTransport):
    """
    A transport that always redirects to HTTPS.
    """

    def handle_request(self, method, url, headers, stream, extensions):
        scheme, host, port, path = url
        if port is None:
            location = b"https://%s%s" % (host, path)
        else:
            location = b"https://%s:%d%s" % (host, port, path)
        stream = httpx.ByteStream(b"")
        headers = [(b"location", location)]
        extensions = {}
        return 303, headers, stream, extensions


# A client where any `http` requests are always redirected to `https`
mounts = {'http://': HTTPSRedirectTransport()}
client = httpx.Client(mounts=mounts)
```

### Testing a Flask application using WSGITransport

Source: https://github.com/encode/httpx/blob/master/docs/advanced/transports.md

Calls directly into a WSGI application using `httpx.WSGITransport` and `httpx.Client`. Pass the Flask application instance to the transport and specify a `base_url` on the client.

```python
from flask import Flask
import httpx


app = Flask(__name__)

@app.route("/")
def hello():
    return "Hello World!"

transport = httpx.WSGITransport(app=app)

    r = client.get("/")
    assert r.status_code == 200
    assert r.text == "Hello World!"
```
