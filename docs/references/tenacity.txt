### tenacity.AsyncRetrying

Source: https://github.com/jd/tenacity/blob/main/doc/source/api.rst

Retrying class for asynchronous functions. Similar to Retrying but designed for use with async/await syntax.

```APIDOC
## tenacity.AsyncRetrying

### Description
Retrying class for asynchronous functions. Configure retry behavior via constructor arguments and await the instance with the async function to retry.

### Usage
```python

### tenacity.retry

### tenacity.RetryCallState

Source: https://github.com/jd/tenacity/blob/main/doc/source/api.rst

Class that represents the state of a retry call. Provides information about the current attempt, outcome, and other details during retry execution.

```APIDOC
## tenacity.RetryCallState

### Description
Represents the state of a retry call, including attempt number, outcome, and other metadata. Used internally by retry logic but may be accessed in custom callbacks.

### Usage
```python

    print(retry_state.attempt_number)
    print(retry_state.outcome)
```
