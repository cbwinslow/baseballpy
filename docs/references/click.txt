### Click group with epilog and subcommand help

Source: https://github.com/pallets/click/blob/main/docs/documentation.md

Defines a Click group with a help string and epilog that shows an example usage. The group's help output lists subcommands, options, and the epilog together. The greet command accepts a positional name and options --count (default 1, shown) and --greeting (default "Hello", shown).

```python
import click

@click.group(
    help="Example Click app with subcommands, options, and positional arguments.",
    epilog=("Examples:\n\n\b\n  python hello.py greet Alice --count 2\n"),
)
def cli() -> None:
    """Run the example CLI."""

@cli.command()
@click.argument("name")
@click.option(
    "--count",
    default=1,
    show_default=True,
    type=click.IntRange(1, None),
    help="Number of greetings to print.",
)
@click.option(
    "--greeting",
    default="Hello",
    show_default=True,
    help="Greeting prefix to use.",
)
def greet(name: str, count: int, greeting: str) -> None:
    """Greet NAME one or more times."""
    for _ in range(count):
        click.echo(f"{greeting} {name}!")

```

```shell-session
  Example Click app with subcommands, options, and positional arguments.

Options:
  --help  Show this message and exit.

Commands:
  greet  Greet NAME one or more times.

  Examples:

    python hello.py greet Alice --count 2
```

### Read config from app directory with click.get_app_dir()

Source: https://github.com/pallets/click/blob/main/docs/utils.md

Use click.get_app_dir() to find the OS-appropriate per-user config directory for an application. This example reads a config.ini file from that directory using ConfigParser and returns a flattened dictionary of section.key values.

```python
import os
import click
import ConfigParser

APP_NAME = 'My Application'
def read_config():
cfg = os.path.join(click.get_app_dir(APP_NAME), 'config.ini')
parser = ConfigParser.RawConfigParser()
parser.read([cfg])
rv = {}
for section in parser.sections():
    for key, value in parser.items(section):
        rv[f"{section}.{key}"] = value
return rv
```

### Invoke and Forward Commands in Click

Source: https://github.com/pallets/click/blob/main/docs/advanced.md

```python
cli = click.Group()

    click.echo(f'Count: {count}')
```

### Override value completion with shell_complete function

Source: https://github.com/pallets/click/blob/main/docs/shell-completion.md

Provide a shell_complete function to a parameter to customize value completion without a custom type. The function receives ctx, param, and incomplete, and returns a list of CompletionItem objects or a list of strings. This example suggests environment variables that start with the incomplete value and is used with a click argument.

```python
def complete_env_vars(ctx, param, incomplete):
    return [k for k in os.environ if k.startswith(incomplete)]

@click.command()
@click.argument("name", shell_complete=complete_env_vars)
def cli(name):
    click.echo(f"Name: {name}")
    click.echo(f"Value: {os.environ[name]}")
```

### Custom ParamType shell_complete() for environment variable completion

Source: https://github.com/pallets/click/blob/main/docs/shell-completion.md

Override the shell_complete() method of a custom ParamType to suggest environment variables that start with the incomplete value. The method must return a list of CompletionItem objects; the built-in implementations use the 'type' and 'help' metadata for special handling and help text. The example defines an EnvVarType and uses it with a click option.

```python
class EnvVarType(ParamType[str]):
    name = "envvar"

    def shell_complete(self, ctx, param, incomplete):
        return [
            CompletionItem(name)
            for name in os.environ if name.startswith(incomplete)
        ]

@click.command()
@click.option("--ev", type=EnvVarType())
def cli(ev):
    click.echo(os.environ[ev])
```

### Ignore unknown options with an UNPROCESSED argument

Source: https://github.com/pallets/click/blob/main/docs/advanced.md

Requires setting 'ignore_unknown_options' and using 'nargs=-1' with 'type=UNPROCESSED' to collect leftover arguments. The example shows a fake wrapper around Python's timeit that forwards options to the command line; unknown options are stored in the argument variable.

### Validate rolls with callback and BadParameter

Source: https://github.com/pallets/click/blob/main/docs/advanced.md

Defines a callback that parses a 'NdM' string into a tuple, raising click.BadParameter on invalid input. The callback runs after type conversion and is used with click.UNPROCESSED type. The example shows the command and its usage, including error output.

```python
def validate_rolls(ctx, param, value):
    if isinstance(value, tuple):
        return value

    try:
        rolls, _, dice = value.partition("d")
        return int(dice), int(rolls)
    except ValueError:
        raise click.BadParameter("format must be 'NdM'")

@click.command()
@click.option(
    "--rolls", type=click.UNPROCESSED, callback=validate_rolls,
    default="1d6", prompt=True,
)
def roll(rolls):
    sides, times = rolls
    click.echo(f"Rolling a {sides}-sided dice {times} time(s)")
```

```shell-session
$ roll --rolls=42
Usage: roll [OPTIONS]
Try 'roll --help' for help.

Error: Invalid value for '--rolls': format must be 'NdM'

$ roll --rolls=2d12
Rolling a 12-sided dice 2 time(s)

$ roll
Rolls [1d6]: 42
Error: format must be 'NdM'
Rolls [1d6]: 2d12
Rolling a 12-sided dice 2 time(s)
```

### Command Aliases: AliasedGroup subclass

Source: https://github.com/pallets/click/blob/main/docs/extending-click.md

Defines a click.Group subclass that accepts unique prefixes for commands. Overrides get_command() to find commands that start with the given name, and resolve_command() to return the full command name. If multiple matches exist, it fails with a message listing them.

```python
class AliasedGroup(click.Group):
    def get_command(self, ctx, cmd_name):
        rv = super().get_command(ctx, cmd_name)

        if rv is not None:
            return rv

        matches = [
            x for x in self.list_commands(ctx)
            if x.startswith(cmd_name)
        ]

        if not matches:
            return None

        if len(matches) == 1:
            return click.Group.get_command(self, ctx, matches[0])

        ctx.fail(f"Too many matches: {', '.join(sorted(matches))}")

    def resolve_command(self, ctx, args):
        # always return the full command name
        _, cmd, args = super().resolve_command(ctx, args)
        return cmd.name, cmd, args
```

### Add ctx argument to ParamType methods for Click 8.2 compatibility

Source: https://github.com/pallets/click/blob/main/docs/support-multiple-versions.md

Use the decorator to wrap ParamType method overrides so they accept the new ctx argument in Click 8.2 while remaining compatible with 8.1. The subclass example shows how to apply it to get_metavar; the same technique works for other methods like get_missing_message.

```python
import functools
import typing as t
import click

F = t.TypeVar("F", bound=t.Callable[..., t.Any])

def add_ctx_arg(f: F) -> F:
    @functools.wraps(f)
    def wrapper(*args: t.Any, **kwargs: t.Any) -> t.Any:
        if "ctx" not in kwargs:
            kwargs["ctx"] = click.get_current_context(silent=True)

        return f(*args, **kwargs)

    return wrapper  # type: ignore[return-value]

```

```python
class CommaDelimitedString(click.ParamType[str]):
    @add_ctx_arg
    def get_metavar(self, param: click.Parameter, ctx: click.Context | None) -> str:
        return "TEXT,TEXT,..."

```

### Use with_resource() in a group to open a resource

### Implement MyshComplete shell completion class

Source: https://github.com/pallets/click/blob/main/docs/shell-completion.md

These three Python blocks implement a custom shell completion class for a made-up shell "mysh". The first defines the source template and registers the class with `add_completion_class()`.
```python
from click.shell_completion import add_completion_class
from click.shell_completion import ShellComplete

_mysh_source = """\
%(complete_func)s {
    response=$(%(complete_var)s=mysh_complete %(foo_bar)s)
    # parse response and set completions somehow
}
call-on-complete %(foo_bar)s %(complete_func)s

@add_completion_class
class MyshComplete(ShellComplete):

    source_template = _mysh_source
```

```python
import os
from click.parser import split_arg_string

class MyshComplete(ShellComplete):
    ...

    def get_completion_args(self):
        args = split_arg_string(os.environ["COMP_WORDS"])

        if os.environ["COMP_PARTIAL"] == "1":
            incomplete = args.pop()
            return args, incomplete

        return args, ""
```

```python
class MyshComplete(ShellComplete):
    ...
```

### Define Repo class as a context manager

Source: https://github.com/pallets/click/blob/main/docs/advanced.md

The Repo class is defined as a context manager, opening a database in __enter__ and closing it in __exit__. This allows it to be used with the with statement.

```python
class Repo:
    def __init__(self, home=None):
        self.home = os.path.abspath(home or ".")
        self.db = None

    def __enter__(self):
        path = os.path.join(self.home, "repo.db")
        self.db = open_database(path)
        return self

    def __exit__(self, exc_type, exc_value, tb):
        self.db.close()
```

### Pass context between nested Click commands

Source: https://github.com/pallets/click/blob/main/docs/commands.md

Shows how to use the Context to pass data between nested commands. The group sets a debug flag on ctx.obj, and the sync command reads it. The final cli(obj={}) call initializes the context object.

```python
@click.group()

@click.pass_context
def cli(ctx, debug):

    # by means other than the `if` block below)
    ctx.ensure_object(dict)

    ctx.obj['DEBUG'] = debug

@cli.command()
@click.pass_context
def sync(ctx):
    click.echo(f"Debug is {'on' if ctx.obj['DEBUG'] else 'off'}")

if __name__ == '__main__':
    cli(obj={})
```

### Pass information in a wrapper object

Source: https://github.com/pallets/click/blob/main/docs/advanced.md

Recommended alternative to modifying params directly. The callback returns a URL object that bundles the URL and the opened file pointer, avoiding the pitfalls of direct params modification.

```python
import urllib.request

class URL:
    def __init__(self, url, fp):
        self.url = url
        self.fp = fp

def open_url(ctx, param, value):
    if value is not None:
        return URL(value, urllib.request.urlopen(value))

@click.command()
@click.option('--url', callback=open_url)
```

### Chainable group with result_callback and processor functions

Source: https://github.com/pallets/click/blob/main/docs/commands.md

Implements a chainable group with a result_callback that processes lines through subcommand-returned functions. Requires invoke_without_command=True to run the result callback when no subcommand is given. Note that Click closes the context after each callback, so file types cannot be used in the processor functions.

```python
@click.group(chain=True, invoke_without_command=True)
@click.argument("fin", type=click.File("r"))
def cli(fin):
    pass

@cli.result_callback()
def process_pipeline(processors, fin):
    iterator = (x.rstrip("\r\n") for x in input)

    for processor in processors:
        iterator = processor(iterator)

    for item in iterator:
        click.echo(item)

@cli.command("upper")
def make_uppercase():
    def processor(iterator):
        for line in iterator:
            yield line.upper()
    return processor

@cli.command("lower")
def make_lowercase():
    def processor(iterator):
        for line in iterator:
            yield line.lower()
    return processor

@cli.command("strip")
def make_strip():
    def processor(iterator):
        for line in iterator:
            yield line.strip()
    return processor

```

### Custom Group: PluginGroup subclass

Source: https://github.com/pallets/click/blob/main/docs/extending-click.md

Defines a click.Group subclass that loads commands from Python files in a folder. Overrides list_commands() to find .py files and get_command() to lazily load the module and return its cli attribute. The group is instantiated with a plugin_folder and executed when run as a script.

```python
import importlib.util
import os
import click

class PluginGroup(click.Group):
    def __init__(self, name=None, plugin_folder="commands", **kwargs):
        super().__init__(name=name, **kwargs)
        self.plugin_folder = plugin_folder

    def list_commands(self, ctx):
        rv = []

        for filename in os.listdir(self.plugin_folder):
            if filename.endswith(".py"):
                rv.append(filename[:-3])

        rv.sort()
        return rv

    def get_command(self, ctx, name):
        path = os.path.join(self.plugin_folder, f"{name}.py")
        spec = importlib.util.spec_from_file_location(name, path)
        module = importlib.util.module_from_spec(spec)
        spec.loader.exec_module(module)
        return module.cli

cli = PluginGroup(
    plugin_folder=os.path.join(os.path.dirname(__file__), "commands")
)

if __name__ == "__main__":
    cli()
```

### Custom integer type accepting hex and octal

Subclass click.ParamType[int] and override convert() to parse hex (0x prefix) and octal (leading 0) strings into integers. The name attribute is optional for documentation. ```python

```python
class BasedIntParamType(click.ParamType[int]):
    name = "integer"

    def convert(self, value, param, ctx) -> int:
        if isinstance(value, int):
            return value

        try:
            if value[:2].lower() == "0x":
                return int(value[2:], 16)
            elif value[:1] == "0":
                return int(value, 8)
```

### Define LazyGroup subclass

Source: https://github.com/pallets/click/blob/main/docs/complex.md

Defines a LazyGroup subclass that lazily loads subcommands by storing a mapping of command names to import paths. Overrides list_commands and get_command to defer imports until needed.

```python
# in lazy_group.py
import importlib
import click

class LazyGroup(click.Group):
    def __init__(self, *args, lazy_subcommands=None, **kwargs):
        super().__init__(*args, **kwargs)
        # lazy_subcommands is a map of the form:
        #
        #   {command-name} -> {module-name}.{command-object-name}
        #
        self.lazy_subcommands = lazy_subcommands or {}

    def list_commands(self, ctx):
        base = super().list_commands(ctx)
        lazy = sorted(self.lazy_subcommands.keys())
        return base + lazy

    def get_command(self, ctx, cmd_name):
        if cmd_name in self.lazy_subcommands:
            return self._lazy_load(cmd_name)
        return super().get_command(ctx, cmd_name)

    def _lazy_load(self, cmd_name):
        # lazily loading a command, first get the module name and attribute name
        import_path = self.lazy_subcommands[cmd_name]
        modname, cmd_object_name = import_path.rsplit(".", 1)
        # do the import
        mod = importlib.import_module(modname)
        # get the Command object from that module
        cmd_object = getattr(mod, cmd_object_name)
        # check the result to make debugging easier
        if not isinstance(cmd_object, click.Command):
            raise ValueError(
                f"Lazy loading of {import_path} failed by returning "
                "a non-command object"
            )
        return cmd_object
```
