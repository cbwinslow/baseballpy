### playerid_lookup examples

Source: https://github.com/jldbc/pybaseball/blob/master/docs/playerid_lookup.md

Examples of using playerid_lookup to find player IDs by last name, first name, and fuzzy matching. The first example returns all players with last name 'jones' (1,314 rows), the second returns Chipper Jones, the third returns all Pedro Martinez players (2 rows), and the fourth returns the 5 closest names to 'yadi molina' with Yadier Molina first.

data = playerid_lookup("molina", "yadi", fuzzy=True)

### team_batting(start_season, end_season=None, league='all', ind=1)

Source: https://github.com/jldbc/pybaseball/blob/master/docs/team_batting.md

Documentation for the team_batting function, including arguments and usage examples.

```APIDOC
## team_batting(start_season, end_season=None, league='all', ind=1)

### Description
Returns a dataframe of team-level batting stats for a single season or multiple seasons. Can provide either single-season stats (one row per team per season) or aggregate stats over all seasons queried.

### Method
Function call

### Endpoint
`team_batting(start_season, end_season=None, league='all', ind=1)`

### Parameters
#### Arguments
- **start_season** (Integer) - Required - The first season for which you want the league's team-level batting data.
- **end_season** (Integer) - Optional - The last season for which you want the league's team-level batting data. If not provided, the query will return data for only the `start_season`.
- **league** (String) - Optional - Either "all" for all data, "nl" for National League, "al" for the American League, or "mnl" for all Negro League data. Defaults to "all".
- **ind** (Integer) - Optional - Flag for whether you want data at the individual-season or aggregate level. If `ind=1`, returns one row per team per year. If `ind=0`, aggregates data so that one row of aggregate stats is provided per team. Defaults to 1.

### Request Example
```python
from pybaseball import team_batting

# get each team's seasonal batting stats from 2010 through 2013
data = team_batting(2010, 2013)

# get each team's aggregate batting stats from 2010 through 2013
data = team_batting(2010, 2013, ind=0)

# get team batting stats for only the 1999 season
data = team_batting(1999)
```

### Response
#### Success Response
Returns a pandas DataFrame containing team-level batting statistics. The structure depends on the `ind` parameter: if `ind=1`, one row per team per season; if `ind=0`, one row per team with aggregate stats over the queried seasons.
```

### statcast_outs_above_average(year, pos, min_att, view)

Source: https://github.com/jldbc/pybaseball/blob/master/docs/statcast_fielding.md

Documentation for the statcast_outs_above_average function from the pybaseball library, including arguments, valid queries, and usage examples.

```APIDOC
## statcast_outs_above_average(year: int, pos: Union[int, str], min_att: Union[int, str] = "q", view: str = "Fielder")

### Description
Retrieves outs above average (OAA) for the given year, position, and attempts. OAA is a Statcast metric based on the cumulative effect of all individual plays a fielder has been credited or debited with, making it a range-based metric of fielding skill that accounts for the number of plays made and the difficulty of them.

### Method
Function call

### Endpoint
statcast_outs_above_average

### Parameters
#### Arguments
- **year** (int) - Required - The year for which you wish to retrieve batted ball against data. Format: YYYY.
- **pos** (Union[int, str]) - Required - The position you are interested in. Valid positions include "all", "IF", "OF", and position names, numbers, or abbreviations. Position numbers may be entered as integers or strings, e.g. 6 or "6" for shortstops. Pitchers and catchers are not included.
- **min_att** (Union[int, str]) - Optional - The minimum number of fielding attempts for the player to be included in the result. Statcast's default is players, which is 1 fielding attempt per game played for 2B, SS, 3B, and OF and 1 fielding attempt per every other game played for 1B.
- **view** (str) - Optional - The perspective by which the OAA numbers should be returned. Statcast default is fielders, which returns typical OOA statistics for all eligible fielders. Valid views include "Fielder" (default) "Pitcher" (OOA of defense behind pitcher), "Fielding_Team", "Batter" (OOA of Defense when player is at-bat), and "Batting_Team". The argument "min_att" is ignored on team based views.

### Request Example
```python
from pybaseball import statcast_outs_above_average

# All fielders with at least 50 fielding attempts in 2019

### pitching_stats(start_season, end_season=None, league='all', qual=1, ind=1)

```APIDOC
## pitching_stats(start_season, end_season=None, league='all', qual=1, ind=1)

### Description
Returns season-level pitching data from FanGraphs. The function retrieves pitching statistics for one or more seasons, with options to filter by league, minimum plate appearances, and aggregation level.

### Method
Function Call

### Endpoint
pitching_stats(start_season, end_season=None, league='all', qual=1, ind=1)

### Parameters
#### Path Parameters
- **start_season** (Integer) - Required - The first season you want to retrieve data from.
- **end_season** (Integer) - Optional - The final season you want to retrieve data from. If omitted, the function will return only data from the start_season.
- **league** (String) - Optional - Either "all" for all data, "nl" for National League, "al" for the American League, or "mnl" for all Negro League data. Defaults to "all", for returning data on all teams. See `FangraphsLeague` definition for all leagues.
- **qual** (Integer) - Optional - Minimum number of plate appearances to be included in the results. Defaults to `None`, which is equivalent to the current Fangraphs "Qualified" PA threshold from their leaderboard.
- **ind** (1 or 0) - Optional - Equals 1 if you want data returned at the individual season level. Equals 0 if you want aggregate data over the seasons included in the query. With `ind=1` and a query spanning the 2010 through 2015 seasons, for example, you will get each player's stats for 2010, 2011, 2012, 2013, 2014, and 2015 in a separate observation. With `ind=0`, this same query returns one row per player with their statistics aggregated over this period (either summed or averaged depending on what's appropriate).

data = pitching_stats(2010, 2016)

# retrieve aggregate player statistics from 2000 to 2016 (i.e.: who has the most wins over this period?)
data = pitching_stats(2010, 2016, ind=0)
```

### Response
#### Success Response
Returns a pandas DataFrame containing season-level pitching statistics. The exact columns depend on the season and the parameters used. Note that larger date ranges will take longer to process.

### Error Handling
- Some of the more modern stats (contact %, zone %, and many others) will not be available before certain dates.

### Calculate cumulative wins, losses, and win percentage for NL Central teams

Source: https://github.com/jldbc/pybaseball/blob/master/EXAMPLES/2018_NL_Central_Analysis.ipynb

Computes cumulative wins, losses, and win percentage for each NL Central team (brewers, cubs, cardinals, pirates, reds) from game-by-game W/L data. Uses np.where to count 'W' and 'W-wo' as wins, 'L' and 'L-wo' as losses, then cumsum for running totals. Requires the team DataFrames to have a 'W/L' column.

```python
# Gets wins-to-date, losses-to-date, and win_percent-to-date for each team
brewers['Wins'] = np.where(brewers['W/L']=='W', 1, (np.where(brewers['W/L']=='W-wo', 1, 0))).cumsum()
brewers['Losses'] = np.where(brewers['W/L']=='L', 1, (np.where(brewers['W/L']=='L-wo', 1, 0))).cumsum()
brewers['Win_Percentage'] = brewers['Wins'] / (brewers['Wins'] + brewers['Losses'])

cubs['Wins'] = np.where(cubs['W/L']=='W', 1, (np.where(cubs['W/L']=='W-wo', 1, 0))).cumsum()
cubs['Losses'] = np.where(cubs['W/L']=='L', 1, (np.where(cubs['W/L']=='L-wo', 1, 0))).cumsum()
cubs['Win_Percentage'] = cubs['Wins'] / (cubs['Wins'] + cubs['Losses'])

cardinals['Wins'] = np.where(cardinals['W/L']=='W', 1, (np.where(cardinals['W/L']=='W-wo', 1, 0))).cumsum()
cardinals['Losses'] = np.where(cardinals['W/L']=='L', 1, (np.where(cardinals['W/L']=='L-wo', 1, 0))).cumsum()
cardinals['Win_Percentage'] = cardinals['Wins'] / (cardinals['Wins'] + cardinals['Losses'])

pirates['Wins'] = np.where(pirates['W/L']=='W', 1, (np.where(pirates['W/L']=='W-wo', 1, 0))).cumsum()
pirates['Losses'] = np.where(pirates['W/L']=='L', 1, (np.where(pirates['W/L']=='L-wo', 1, 0))).cumsum()
pirates['Win_Percentage'] = pirates['Wins'] / (pirates['Wins'] + pirates['Losses'])

reds['Wins'] = np.where(reds['W/L']=='W', 1, (np.where(reds['W/L']=='W-wo', 1, 0))).cumsum()
reds['Losses'] = np.where(reds['W/L']=='L', 1, (np.where(reds['W/L']=='L-wo', 1, 0))).cumsum()
reds['Win_Percentage'] = reds['Wins'] / (reds['Wins'] + reds['Losses'])
```

- **pitcher_pov** (bool) - Optional - If `True`, then direction of movement is from the pitcher's point of view. If `False`, then it is from the batter's point of view.

### Request Example

### Python: Isolate imputations by bb_type and year

Source: https://github.com/jldbc/pybaseball/blob/master/EXAMPLES/imputed_derivation.ipynb

Iterates over years and batted ball types, groups by launch_angle and launch_speed, computes the fraction of total, and prints the top 5 rows for each combination. The output shows the top pairs for each batted ball type and year.

```python
for year,df in zip(range(2015, 2021),dfs):
    for bb_type in dfs[0].bb_type.dropna().unique():
        # Isolate each bb_type
        i = df[df["bb_type"] == bb_type]
        # Sort by pairs of launch angle and speed
        i = i.groupby(["launch_angle", "launch_speed"]).size().reset_index(name="count").sort_values("count", ascending=False)
        # Derive fraction of total
        i["fraction"] = i["count"] / i["count"].sum()
        print(f"bb_type: {bb_type}, year: {year}")
        print(i.head(5))
```

### statcast_pitcher_spin(start_dt, end_dt, player_id)

Source: https://github.com/jldbc/pybaseball/blob/master/docs/statcast_pitcher_spin.md

Retrieves pitch-level Statcast data for a given pitcher and date range, and calculates spin-related metrics. The function returns a pandas DataFrame with the original Statcast data plus added columns for Magnus effect movement and spin axis angles.

```APIDOC
## statcast_pitcher_spin(start_dt, end_dt, player_id)

### Description
Retrieves pitch-level Statcast data for a given pitcher and date range, and calculates spin-related metrics. The function returns a pandas DataFrame with the original Statcast data plus added columns for Magnus effect movement and spin axis angles.

### Method
Function call (Python SDK)

### Endpoint
`statcast_pitcher_spin(start_dt, end_dt, player_id)`

### Parameters
- **start_dt** (string, format: YYYY-MM-DD) - Optional - First day for which to retrieve data. Defaults to yesterday's date if not provided. If only one date is needed, supply start_dt without end_dt.
- **end_dt** (string, format: YYYY-MM-DD) - Optional - Last day for which to retrieve data. Defaults to None. If retrieving data for more than one day, both start_dt and end_dt must be provided.
- **player_id** (integer) - Required - MLBAM player ID for the pitcher. To find a player's MLBAM ID, use the `playerid_lookup` function.

### Return Value
Returns a pandas DataFrame containing pitch-level Statcast data with the following added columns:
- **Mx** (float) - The amount of movement in the x-direction due to the Magnus effect alone. Positive is towards first base/catcher's right.
- **Mz** (float) - The amount of movement in the z-direction due to the Magnus effect alone. Positive is upwards.
- **theta** (float) - The angle of the spin axis with respect to its movement between 0 and 90 degrees. 0 means the spin axis is perpendicular to movement (all 'useful' spin); 90 means parallel (like a gyroball).
- **phi** (float) - The angle of the spin axis in the x-z plane oriented to the x-axis, from the catcher's eye.

### Example Usage
```python
from pybaseball import statcast_pitcher_spin
from pybaseball import playerid_lookup

# find player id
playerid_lookup('darvish','yu')

# get all available data within date range
data = statcast_pitcher_spin('2019-07-01', '2019-07-31', player_id = 506433)

# get data for a single day
data = statcast_pitcher_spin('2019-05-03', player_id = 543294)
```

### Notes
- This method piggybacks off of the `statcast_pitcher` method and is therefore prone to any issue or bug in it.
- The method's calculations were modeled from the work of Professor Alan Nathan of the University of Illinois.
- The axes referred to are the PITCHf/x coordinate system, where the origin is home plate, the x-axis points to the catcher's right, the y-axis towards the mound, and the z-axis upward. So a pitch generally moves in the -y direction.
- These calculations are sensitive to the environment (temperature, barometric pressure, humidity, altitude, windspeed, etc.). All calculations are done as if the pitches were thrown at Tropicana Field, which has no wind and a constant temperature of 70 degrees.
```

### Calculate fraction per year and flag possible imputations

Source: https://github.com/jldbc/pybaseball/blob/master/EXAMPLES/imputed_derivation.ipynb

For each year and batted ball type, groups by launch angle and speed, calculates the fraction of total, and flags rows exceeding the threshold. Accumulates flagged rows into a summary dataframe.

```python
threshold = 0.002
summary = None
for year,df in zip(range(2015, 2021),dfs):
    for bb_type in dfs[0].bb_type.dropna().unique():
        # Isolate each bb_type
        i = df[df["bb_type"] == bb_type]
        # Sort by pairs of launch angle and speed
        i = i.groupby(["launch_angle", "launch_speed"]).size().reset_index(name="count").sort_values("count", ascending=False)
        # Derive fraction of total
        i["fraction"] = i["count"] / i["count"].sum()
        # Flagging as possibly imputed criterion
        i["flag"] = (i["fraction"] > threshold)
        i["bb_type"] = bb_type
        i["year"] = year
        flagged = i[i["flag"] == True]


        # Add to dataframe (or create on first iteration)
        if summary is not None:
            summary = summary.append(flagged[["launch_angle","launch_speed","count","bb_type","year"]])
        else:
            summary = flagged[["launch_angle","launch_speed","count","bb_type","year"]]
```

### statcast_catcher_poptime(year, min_2b_att, min_3b_att)

Source: https://github.com/jldbc/pybaseball/blob/master/docs/statcast_fielding.md

Function to retrieve catcher pop time data from Statcast.

```APIDOC
## statcast_catcher_poptime(year: int, min_2b_att: int, min_3b_att: int)

### Description
Retrieves pop time data for catchers given year and minimum stolen base attempts for second and third base. Pop time is measured as the time from the moment the ball hits the catcher's mitt to when it reaches the projected receiving point at the center of the fielder's base. Note: It is not available for 2020 data.

### Method
Function Call

### Endpoint
statcast_catcher_poptime(year, min_2b_att, min_3b_att)

### Parameters
- **year** (int) - Required - The year for which you wish to retrieve batted ball against data. Format: YYYY.
- **min_2b_att** (int) - Required - The minimum number of stolen base attempts for second base against the catcher. Statcast's default is 5.
- **min_3b_att** (int) - Required - The minimum number of stolen base attempts for third base against the catcher. Statcast's default is 0.

### Request Example
```python
from pybaseball import statcast_catcher_poptime

# Catchers with at least 10 second base attempts against and 2 third base attempts against in 2019
data = statcast_catcher_poptime(2019, min_2b_att = 10, min_3b_att = 2)
```

### Response
Returns a pandas DataFrame containing catcher pop time data for the specified year and minimum attempts.

### add_spray_angle(df, adjusted=False)

Source: https://github.com/jldbc/pybaseball/blob/master/docs/statcast_utils.md

Adds spray angle and adjusted spray angle to StatCast DataFrames. Spray angle is the raw left-right angle of the hit, while adjusted spray angle flips the sign for left-handed batters to create a push/pull angle.

```APIDOC
## add_spray_angle(df, adjusted=False)

### Description
Adds spray angle and adjusted spray angle to StatCast DataFrames. Spray angle is the raw left-right angle of the hit. Adjusted spray angle flips the sign for left-handed batters, making it a push/pull angle.

### Method
Function

### Endpoint
`pybaseball.datahelpers.statcast_utils.add_spray_angle`

### Parameters
- **df** (pd.DataFrame) - Required - StatCast pd.DataFrame (retrieved through statcast, statcast_batter, etc.)
- **adjusted** (Optional[bool]) - Optional - If True, adds adjusted spray angle (default False)

### Returns
- **df** (pd.DataFrame) - The input DataFrame with added columns `spray_angle` and optionally `adj_spray_angle`.

### Example
```python
from pybaseball.datahelpers.statcast_utils import add_spray_angle
from pybaseball import statcast

df = statcast("2018-05-01","2018-05-02")
# get hits
df = df[~df["bb_type"].isna()]
# Add Spray angle
df = add_spray_angle(df)
print("Spray Angle:")
print(df["spray_angle"][0:5])
df = add_spray_angle(df, adjusted=True)
print("Adjusted Spray Angle:")
print(df["adj_spray_angle"][0:5])
```
